## 🚀 Quick Start

1. **Start the application:**
   ```bash
   ./run.sh
   ```

2. **Access the application:**
   - Main app: http://localhost:8501
   - API docs: http://localhost:8501/docs
   - Health check: http://localhost:8501/health

3. **Demo login:**
   - Username: `demo`
   - Password: `password`

## 📖 API Endpoints

### Authentication
- `POST /auth/login` - Get access token
- `GET /auth/validate` - Validate token

### Workouts  
- `POST /api/workouts` - Log workout
- `GET /api/workouts` - Get workout history

### Nutrition
- `POST /api/nutrition` - Log nutrition entry
- `GET /api/nutrition` - Get nutrition history

### Measurements
- `POST /api/measurements` - Record body measurement
- `GET /api/measurements` - Get measurement history

### Analytics
- `GET /api/analytics/progress` - Progress analytics
- `GET /api/analytics/dashboard` - Dashboard data

## 🔧 Configuration

Environment variables in `.env`:
- `JWT_SECRET` - JWT signing secret (change in production!)
- `PORT` - Service port (default: 8501)
- `ENVIRONMENT` - Runtime environment
