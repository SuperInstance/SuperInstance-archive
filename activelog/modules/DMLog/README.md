# DMLog.ai Core RPG Engine

A comprehensive tabletop RPG engine supporting multiple game systems including D&D 5e, Pathfinder, Call of Cthulhu, Shadowrun, and Vampire the Masquerade.

## Architecture

The engine is built with a modular architecture:

- **Core Engine**: Base interfaces and abstractions
- **Game Systems**: Specific implementations for different RPG systems
- **Character Management**: Flexible character sheet system
- **Dice System**: Advanced dice mechanics with various rule support
- **Combat Engine**: Turn-based combat with initiative and conditions
- **Spell/Power System**: Magic and special abilities framework
- **Campaign Tools**: Session and campaign management

## Supported Systems

- D&D 5th Edition
- Pathfinder 1e/2e
- Call of Cthulhu 7th Edition
- Shadowrun 5th/6th Edition
- Vampire the Masquerade 5th Edition
- Savage Worlds
- FATE Core

## Features

- Flexible attribute and skill systems
- Advanced dice rolling with modifiers
- Combat tracking and initiative
- Spell slot and power point management
- Character progression and leveling
- Equipment and inventory management
- Condition and status effect tracking
