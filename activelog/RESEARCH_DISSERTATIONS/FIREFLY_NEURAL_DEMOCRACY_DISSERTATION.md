### 4.1 Neuron Voting Mechanisms

Each neuron participates in democratic resource allocation through sophisticated voting mechanisms:

**Performance-Based Affinity Updates**:
```python
def update_affinity(neuron, firefly_model, success, brightness_achieved):
    current_affinity = neuron.affinities[firefly_model]
    
    # Performance score: 60% success rate, 40% brightness quality
    performance_score = 0.6 * success + 0.4 * brightness_achieved
    
    # Learning rate based on confidence in assessment
    learning_rate = min(0.1, 1.0 / neuron.interaction_count[firefly_model])
    
    # Update affinity with performance feedback
    new_affinity = current_affinity + learning_rate * (performance_score - current_affinity)
    neuron.affinities[firefly_model] = max(0.1, min(1.0, new_affinity))
```

**Trend Analysis**: Neurons track performance trends (improving, declining, stable) to weight recent performance more heavily than historical averages.

**Vote Weight Calculation**: Neuron voting influence depends on:
- Overall activation probability (brighter neurons have more influence)
- Connection centrality (well-connected neurons have more influence)  
- Historical prediction accuracy (neurons that make good predictions gain influence)
