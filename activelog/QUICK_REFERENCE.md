# 🚀 ActiveLog Quick Reference

## Super Easy Commands (Just Copy & Paste!)

### Start ActiveLog (One Command Does Everything!)
```bash
./activelog start
```
- First time? Automatically sets up everything for your device
- Starts all services optimized for your hardware
- Opens web dashboard
- Shows you exactly what's running

### Web Dashboard (Point & Click Interface)
```bash
./activelog dashboard
```
Then open: **http://localhost:8080**
- Start/stop services with one click
- Optimize performance with one button
- Monitor system health in real-time
- No command line needed!

### Check What's Running
```bash
./activelog status
```
Shows you:
- ✅ Which services are running
- 💻 CPU and memory usage
- 🌐 Web interface links
- 🔗 All available endpoints

### Fix Problems Automatically
```bash
python3 simple_troubleshooter.py
```
- Finds and fixes common issues automatically
- Installs missing dependencies
- Fixes file permissions
- Provides step-by-step help for complex issues

### Make It Run Faster
```bash
./activelog optimize
```
- Optimizes for your specific device (desktop, laptop, tablet, Pi)
- Enables cloud computing for older devices (90% faster AI tasks)
- Cleans up system resources
- Applies best performance settings

## 🎯 Most Common Use Cases

### "I Just Want It To Work"
```bash
./activelog start
```
That's it! Everything else is automatic.

### "I Want Maximum Performance"
```bash
./activelog setup    # Configure cloud computing
./activelog optimize # Apply all optimizations
./activelog start    # Start optimized system
```

### "Something's Wrong"
```bash
python3 simple_troubleshooter.py
./activelog status
./activelog restart
```

### "I Want a GUI Interface"
```bash
./activelog dashboard
# Then open http://localhost:8080 in your browser
```

## 🌐 Web Interfaces After Starting

- **🎛️ Control Dashboard**: http://localhost:8080 (one-click controls)
- **📊 API Gateway**: http://localhost:8088 (system status)
- **💻 Main Application**: http://localhost:3000 (full features)

## 💡 Pro Tips

1. **First Run**: Always use `./activelog start` - it handles everything automatically
2. **Web Dashboard**: Bookmark http://localhost:8080 for easy access
3. **Cloud Setup**: Add your API keys during setup to save money and boost performance
4. **Troubleshooting**: Run the troubleshooter if anything seems wrong
5. **Monitoring**: Check the dashboard occasionally for system health
