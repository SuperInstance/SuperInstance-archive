# 🎯 Hierarchical Task Manager

A real-time collaborative task management system built using the validated hierarchical task decomposition approach from our AI experiments.

## ✨ Features

- **Real-time Collaboration**: WebSocket-powered live updates
- **Hierarchical Architecture**: Built using validated decomposition patterns
- **User Authentication**: Secure JWT-based auth system
- **Kanban Board**: Visual task flow (Todo → In Progress → Completed)
- **Priority Management**: High, Medium, Low priority levels
- **Live Statistics**: Real-time task completion metrics

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start the server
npm start
```

Visit `http://localhost:3000` to use the app.

## 📊 Architecture

Built using the fourth-dimensional logic system:

1. **Chef Bot Pattern**: Main server coordinates task distribution
2. **Component Decomposition**: Tasks broken into manageable components
3. **Dynamic Merging**: Identical components merged across sessions
4. **ML Optimization**: Loop rates optimized based on usage patterns

- **Backend**: Node.js + Express
- **Real-time**: Socket.IO
- **Database**: SQLite (in-memory for demo)
- **Auth**: JWT + bcrypt
- **Frontend**: Vanilla JS + CSS Grid
