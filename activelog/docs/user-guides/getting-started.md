# Getting Started with ActiveLog

Welcome to ActiveLog! This guide will help you get up and running quickly with our intelligent file management platform.

## What is ActiveLog?

ActiveLog is an AI-powered file management system that helps you:
- 🔍 **Find files instantly** with intelligent search
- 🤖 **Auto-organize** content with AI classification  
- 🔄 **Sync across devices** seamlessly
- 👥 **Collaborate** in real-time with your team
- 📊 **Gain insights** from your data patterns

## Quick Setup (5 minutes)

### Step 1: Create Your Account

1. Visit [https://app.activelog.com](https://app.activelog.com)
2. Click **"Sign Up"** in the top right corner
3. Choose your signup method:
   - 📧 Email and password
   - 🔗 Google/Microsoft SSO
   - 🏢 Enterprise SSO (if enabled)

![Screenshot Placeholder: Account creation form]

### Step 2: Verify Your Email

1. Check your email for a verification link
2. Click **"Verify Account"** 
3. You'll be redirected to the ActiveLog dashboard

💡 **Pro Tip**: Add `noreply@activelog.com` to your contacts to ensure you receive all notifications.

### Step 3: Complete Your Profile

1. Upload a profile picture (optional)
2. Set your display name
3. Choose your timezone
4. Select notification preferences

![Screenshot Placeholder: Profile setup page]

### Step 4: Install Desktop App (Recommended)

Download the desktop app for the best experience:

**Windows:**
```
Download: https://releases.activelog.com/windows/ActiveLogSetup.exe
```

**macOS:**
```  
Download: https://releases.activelog.com/mac/ActiveLog.dmg
```

**Linux:**
```bash
# Ubuntu/Debian
wget https://releases.activelog.com/linux/activelog.deb
sudo dpkg -i activelog.deb

# Fedora/RHEL
sudo rpm -i https://releases.activelog.com/linux/activelog.rpm
```

![Screenshot Placeholder: Desktop app installation]

### Step 5: Your First File Upload

Let's upload your first file:

1. **Drag and drop** a file into the dashboard, or
2. Click **"Upload Files"** button
3. Select files from your computer
4. Choose a folder (or create a new one)
5. Click **"Upload"**

![Screenshot Placeholder: File upload interface]

✅ **Success!** Your file is now uploaded and being processed by AI.

## Quick Wins (Try These Now!)

### ⚡ Power Search
Type `@` followed by:
- `@today` - Files from today
- `@images` - All images
- `@large` - Files over 100MB
- `@shared` - Files shared with others

### 🏷️ Smart Tagging
- Type `#` to add tags instantly
- Use `#work #important #Q4` for complex organization
- Tags appear as you type with auto-complete

### 🔄 Version History
- Right-click any file → **"Version History"**
- See all changes over time
- Restore previous versions instantly

### 📊 Quick Analytics
- Click your avatar → **"Analytics"** 
- See storage usage, file types, activity patterns
- Discover insights about your data

## Common First-Time Questions

### ❓ "Where are my files stored?"
Your files are stored securely in enterprise-grade cloud storage with end-to-end encryption. You can also set up local sync for offline access.

### ❓ "How does AI work with my files?"
AI processes metadata only (file names, types, extracted text) - not personal content. All processing happens on secure servers with privacy protection.

### ❓ "Can I import from other services?"
Yes! Use **File → Import** to bring in files from:
- Google Drive
- Dropbox  
- OneDrive
- Local folders
- Box, iCloud, and more

### ❓ "What about privacy and security?"
ActiveLog is built with privacy-first design:
- 🔐 End-to-end encryption
- 🛡️ SOC 2 Type II compliant
- 🌍 GDPR compliant
- 📋 Regular security audits

## Keyboard Shortcuts

Master these shortcuts for faster navigation:

| Shortcut | Action |
|----------|---------|
| `Ctrl/Cmd + K` | Open search |
| `Ctrl/Cmd + U` | Upload files |  
| `Space` | Preview file |
| `Ctrl/Cmd + D` | Download file |
| `F2` | Rename file |
| `Delete` | Move to trash |
| `Ctrl/Cmd + Z` | Undo action |
| `Ctrl/Cmd + /` | Show all shortcuts |
