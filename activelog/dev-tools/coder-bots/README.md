## 🤖 CODER BOT TYPES & USAGE

### **1. CODE ANALYZER BOT** 📊
**Purpose**: Deep code analysis, architecture understanding, dependency mapping

```bash
# Analyze a service
./bots/code-analyzer/analyze-service.py --service auth --output-format json

# Generate architecture diagram
./bots/code-analyzer/generate-architecture.py --services "auth,api-gateway,ai-insights"

# Find circular dependencies
./bots/code-analyzer/dependency-analysis.py --check-cycles
```

**Output Example:**
```json
{
  "service": "auth",
  "complexity_score": 7.2,
  "dependencies": ["fastapi", "jwt", "sqlalchemy"],
  "architecture_patterns": ["repository", "dependency_injection"],
  "optimization_suggestions": [
    "Consider caching JWT token validation",
    "Database connection pooling recommended"
  ]
}
```

### **2. TEST GENERATOR BOT** 🧪
**Purpose**: Automated test creation for comprehensive coverage

```bash
# Generate unit tests for a service
./bots/test-generator/generate-tests.py --service businesslog-backend --test-type unit

# Create integration tests
./bots/test-generator/generate-integration-tests.py --services "auth,api-gateway"

# Generate load tests
./bots/test-generator/generate-load-tests.py --endpoint "/api/v1/workouts" --users 1000
```

**Generated Test Example:**
```python
# Auto-generated by Test Generator Bot
import pytest
from fastapi.testclient import TestClient
from services.auth.main import app

client = TestClient(app)

def test_auth_health_endpoint():
    """Test auth service health check - Generated by Test Bot"""
    response = client.get("/health")
    assert response.status_code == 200
    assert response.json()["status"] == "healthy"
```
