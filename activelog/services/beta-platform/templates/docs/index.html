API Endpoints

Access the platform programmatically through our REST API:

  • /api/feedback - Feedback collection endpoints
  • /api/bugs - Bug reporting with screenshots
  • /api/features - Feature requests and voting
  • /api/rewards - Rewards and point system
  • /api/rollout - Staged rollout management
  • /api/monitoring - Performance monitoring
  • /api/crashes - Crash reporting system
  • /api/analytics - Usage analytics
  • /api/ab-testing - A/B testing framework
