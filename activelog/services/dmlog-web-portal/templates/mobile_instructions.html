Detailed Setup Instructions

📱 Step 1: Download Expo Go

Expo Go is a free app that lets you run React Native apps without installing from the App Store.

  1. Open the App Store on your iPhone
  2. Search for "Expo Go"
  3. Install the app (it's completely free)
  4. Open Expo Go when installation is complete
✅ Pro Tip: Expo Go is made by the same team that created React Native. It's trusted by millions of developers worldwide.

🔗 Step 2: Connect to DMLog Server

The mobile app connects to the same backend server you're using right now.

Server Connection Info:

Backend URL: http://localhost:8099

The app will automatically connect to this server for all data.

  1. Make sure your phone is on the same WiFi network as this computer
  2. The app will automatically find and connect to the backend server
  3. All your character data, spells, and voice commands sync instantly

🎯 Step 3: Launch the App

Multiple ways to open the DMLog Revolutionary app:

🎯 Option A: QR Code (Easiest)

  • Open your iPhone Camera app
  • Point it at the QR code above
  • Tap the notification that appears
  • Choose "Open in Expo Go"

🔗 Option B: Direct Link

  • Open Expo Go app
  • Tap "Enter URL manually"
  • Type: exp://exp.host/@your-username/dmlog-mobile
  • Tap "Connect"
⚠️ Troubleshooting: If the app doesn't load, make sure you're on the same WiFi network and the backend server is running (it should be!).
