📚 Integration Steps

  1. Include the Script: Add the SuperInstance AI script to your website
  2. Configure Options: Set your API endpoint, user ID, and preferences
  3. Customize Appearance: Adjust position, theme, and styling to match your site
  4. Enable Admin Mode: For administrators, use "admin_max" as the user ID
  5. Test Voice Features: Ensure microphone permissions are granted

🔒 Admin Setup:

To enable admin developer mode:

  1. Set userId to "admin_max" in the configuration
  2. Say "enable developer mode" or "turn on developer mode"
  3. You'll see the widget turn green indicating admin status
  4. Now you can generate code, modify defaults, and approve user changes
