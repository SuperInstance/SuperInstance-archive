# FishingLog Marine Layouts

Specialized navigation and fishing layouts optimized for different maritime activities.

## Layout Types

### Helm Layout
Primary command and control interface combining chart navigation with essential instruments and radar for active boat handling.

### Navigation Layout  
Dedicated route planning and navigation interface with weather overlay for passage planning and course management.

### Fishing Layout
Specialized fishing interface combining chart plotter with fish finder sonar and catch logging capabilities.

### Docking Layout
Close-quarters maneuvering interface with chart, camera feeds, and real-time wind/current data for safe docking operations.

### Passage Layout
Long-distance cruising interface with chart, weather routing, and watchkeeping schedule management.

### Emergency Layout
Crisis management interface combining chart with AIS traffic, emergency communications, and distress signaling capabilities.

## Technical Implementation

Each layout provides:
- Responsive design for marine displays
- Touch-optimized controls for gloved hands
- Night mode for low-light conditions  
- Configurable widget placement
- Real-time data integration
- Export capabilities for logging

## Usage

Layouts can be selected based on current maritime activity and automatically adapt instrument priorities and data displays accordingly.
