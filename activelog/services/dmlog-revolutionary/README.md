## 🚀 Quick Start Guide

### **Prerequisites**
```bash
# Backend Requirements
Python 3.11+
PostgreSQL 14+
Redis 7+
Node.js 18+

# Optional (for full AI features)
NVIDIA GPU with CUDA support
OpenAI API key or local Ollama installation
```

### **Installation**
```bash
# 1. Clone the repository
git clone https://github.com/activelog/dmlog-revolutionary
cd dmlog-revolutionary

# 2. Start backend services
cd services/dmlog-revolutionary
pip install -r requirements.txt
python character-engine.py  # Port 8600
python campaign-master.py   # Port 8601

# 3. Start frontend
cd frontend
npm install
npm start  # Port 3000

# 4. Access the revolution
open http://localhost:3000
```

### **Docker Deployment**
```bash
# Full stack with one command
docker-compose up -d

# Services will be available at:
# Frontend: http://localhost:3000
# Character Engine: http://localhost:8600
# Campaign Master: http://localhost:8601
# PostgreSQL: localhost:5432
# Redis: localhost:6379
```
