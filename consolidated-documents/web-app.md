# Web Application Quick Start

Get started with the ActiveLog web application in under 10 minutes. This guide covers everything from first login to performing your first core actions.

## 🎯 What You'll Learn
- How to access and log into the web application
- Navigate the main interface
- Complete essential first-time setup
- Perform key workflows
- Get help when you need it

## ⏱️ Estimated Time: 5-10 minutes

## 📋 Prerequisites

Before starting, ensure you have:
- ✅ ActiveLog beta invitation email
- ✅ Signed NDA agreement
- ✅ Modern web browser (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- ✅ Stable internet connection
- ✅ Email access for verification

## 🚀 Step 1: Access the Application

### 1.1 Open Your Browser
Navigate to the beta web application:
```
https://beta.activelog.dev
```

> **Note**: The beta URL is different from the production site. Make sure you're using the beta link from your invitation email.

### 1.2 First-Time Access
If this is your first visit, you'll see:
- Welcome screen with beta program information
- Link to sign the NDA (if not already completed)
- Login form

### 1.3 Account Activation
If you haven't activated your account yet:
1. Check your email for the beta invitation
2. Click "Accept Beta Invitation"
3. Complete the activation form
4. Verify your email address

## 🔐 Step 2: Login

### 2.1 Standard Login
1. Enter your email address
2. Enter your password
3. Click "Sign In"

### 2.2 Two-Factor Authentication (if enabled)
1. Enter the 6-digit code from your authenticator app
2. Or check your email for a verification code
3. Click "Verify"

### 2.3 Troubleshooting Login Issues
**Forgot Password?**
- Click "Forgot Password" link
- Enter your email address
- Check for reset email (may take 2-3 minutes)

**Account Locked?**
- Wait 15 minutes and try again
- Or contact beta-support@activelog.dev

**Beta Access Issues?**
- Verify you're using the beta URL
- Check that your invitation hasn't expired
- Ensure NDA is signed

## 🏠 Step 3: Explore the Interface

### 3.1 Main Dashboard
After login, you'll see the main dashboard with:

**Navigation Bar** (Top)
- ActiveLog logo (home button)
- Search bar
- Notifications bell
- User menu (profile, settings, help)

**Sidebar** (Left)
- Dashboard (home)
- Files & Documents
- Projects & Workspaces
- Analytics & Reports
- Settings
- Beta Features (special section)

**Main Content Area** (Center)
- Welcome message for new beta users
- Recent activity feed
- Quick action buttons
- Usage statistics (if any data exists)

**Status Bar** (Bottom)
- Connection status
- Beta version information
- Feedback button

### 3.2 Beta-Specific Elements
Look for these beta-only features:
- 🧪 **Beta badge** on experimental features
- 💬 **Feedback prompt** for new features
- 🎯 **Feature flags notice** when features are toggled
- 📊 **Usage tracking consent** banner

## ⚙️ Step 4: Essential First-Time Setup

### 4.1 Complete Your Profile
1. Click your avatar in the top-right corner
2. Select "Profile Settings"
3. Fill in required information:
   - Display name
   - Time zone
   - Language preference
   - Profile picture (optional)
4. Click "Save Changes"

### 4.2 Configure Notifications
1. Go to Settings → Notifications
2. Choose your preferences:
   - Email notifications (recommended: enabled)
   - Browser notifications
   - Beta update notifications (recommended: enabled)
   - Feedback requests
3. Save your settings

### 4.3 Accept Beta Terms
1. You may see a beta-specific terms popup
2. Read the beta testing guidelines
3. Accept the terms to continue
4. Note any restrictions on data sharing

### 4.4 Tour the Beta Features
1. Look for the "Beta Features" section in the sidebar
2. Click through to see experimental features
3. Enable features you want to test
4. Read feature descriptions and known limitations

## 📁 Step 5: Perform Your First Actions

### 5.1 Create Your First Project/Workspace
1. Click "New Project" or "Create Workspace"
2. Enter a name: "My Beta Testing Project"
3. Add a description (optional)
4. Choose privacy settings
5. Click "Create"

### 5.2 Upload Your First File
1. Navigate to your new project
2. Click "Upload Files" or drag and drop
3. Select a test file from your computer
4. Wait for upload to complete
5. Verify the file appears in your project

### 5.3 Try a Core Feature
Choose one key feature to test:

**Document Management**
- Create a new document
- Add some content
- Save and share

**Analytics Dashboard**  
- View usage statistics
- Explore data visualizations
- Export a report

**Collaboration Features**
- Invite another beta user
- Start a shared workspace
- Try real-time editing (if available)

## 📱 Mobile Optimization

The web app is optimized for mobile browsers:
- **Responsive Design**: Adapts to screen size
- **Touch Gestures**: Swipe, pinch, tap interactions
- **Offline Support**: Limited offline functionality
- **Add to Home Screen**: Install as PWA on mobile

To use on mobile:
1. Open beta.activelog.dev in mobile browser
2. Login with same credentials
3. Tap browser menu → "Add to Home Screen"
4. Use as native-like app

## ⚡ Performance Tips

**For Best Performance:**
- Use Chrome or Firefox for optimal experience
- Ensure good internet connection (5+ Mbps recommended)
- Close unnecessary browser tabs
- Clear browser cache if experiencing issues
- Update your browser to latest version

**Browser Settings:**
- Enable JavaScript (required)
- Allow notifications (recommended)
- Enable cookies (required)
- Allow camera/microphone (for some beta features)

## 🐛 Common Issues & Solutions

### Login Problems
**Issue**: Can't login with correct credentials
**Solution**: Clear browser cache and cookies, try incognito mode

**Issue**: "Beta access denied" message  
**Solution**: Verify NDA is signed and invitation hasn't expired

### Performance Issues
**Issue**: Slow loading times
**Solution**: Check internet connection, try different browser

**Issue**: Features not working properly
**Solution**: Ensure JavaScript is enabled, update browser

### Feature Access Issues
**Issue**: Can't see beta features
**Solution**: Check if features are enabled in Settings → Beta Features

**Issue**: Missing functionality
**Solution**: Some features may be rolled out gradually or A/B tested
